# Dynamic Branch Prediction Unit — Verilog RTL + Python Analysis

**MCA Project 5, Modern Computer Architecture.** A synthesizable hardware
branch-prediction unit that reduces control-hazard penalties in a 5-stage
MIPS-style pipeline. It contains three prediction strategies (static
not-taken, 1-bit BHT, 2-bit saturating-counter BHT), a tagged Branch Target
Buffer and a pipeline flush/control interface. Every strategy is verified
against a Python golden model on loop-oriented BEQ/BNE traces and compared
by accuracy, misprediction rate and CPI.

## Architecture

```
            IF stage                                        EX stage
 fetch_pc ──► index pc[5:2] ──► BHT (static | 1-bit | 2-bit) ─ dir_taken ─┐
          └─► index/tag      ──► BTB (valid | tag | target)  ─ hit/target ┤
                                                                          ▼
                                                  bp_select_logic: pred_taken, pred_target
 resolved branch ──► bp_update_logic ──► BHT write (every branch), BTB write (taken only)
 resolved branch + carried prediction ──► flush_ctrl ──► mispredict, flush, correct_pc, counters
 next_pc = flush ? correct_pc : pred_target                               (bpu_top)
```

Module hierarchy (`bpu_top` is the complete unit):

```
bpu_top                         (Mayank)
├── branch_predictor_top        (Keshav)
│   ├── bp_update_logic         (Keshav)
│   ├── static_not_taken | bht_1bit | bht_2bit   (Arun; selected by parameter SCHEME)
│   ├── btb                     (Keshav)
│   └── bp_select_logic         (Keshav)
└── flush_ctrl                  (Mayank)
```

## Headline results (16-entry BHT/BTB, penalty 2 cycles, branch frequency 0.2)

All values are from `results/accuracy_table.md`, generated by `make test report`.

| Scheme | Accuracy (all 1256 branches) | Mispredictions | CPI | Speedup vs static NT |
|---|---:|---:|---:|---:|
| Static NT | 30.33 % | 875 | 1.2787 | 1.000 |
| 1-bit BHT | 61.94 % | 478 | 1.1522 | 1.110 |
| 2-bit BHT | 68.31 % | 398 | 1.1268 | 1.135 |

On the 10-iteration loop: static NT 10 %, 1-bit 80 %, 2-bit 89 %.

## Design rules followed

- Synthesizable Verilog-2005: no latches, no `#` delays and no `initial` blocks in `rtl/`
  (Yosys `check -assert` passes and reports 0 latches).
- `iverilog -Wall` reports no warnings (`make lint`).
- Fully parameterized: `PC_WIDTH`, `BHT_INDEX_BITS`, `BTB_INDEX_BITS`, `CTR_WIDTH`, `SCHEME`, `MISPREDICT_PENALTY`.
- Synchronous active-high reset: 1-bit entries → not taken, 2-bit counters → `01` (weakly not taken), BTB valid bits → 0.
